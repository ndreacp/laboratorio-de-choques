# Laboratorio de Choques

Página interactiva para aprender **cantidad de movimiento (momento lineal) y su conservación**: 5 lecciones guiadas, un simulador de choques en un riel de aire y una zona de práctica (cuestionario, clasificación de choques y tarjetas de memoria) con barra de progreso.

Basada en la lectura preclase “Momento lineal y su conservación”.

**Abrir la página:** https://andrea-1c.github.io/laboratorio-de-choques/
